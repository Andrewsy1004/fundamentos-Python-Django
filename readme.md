## 📝 Aplicación para la gestión de notas personalizadas

Esta app permite a los usuarios crear y gestionar notas personalizadas. Incluye funcionalidades como:

- ➕ Creación de notas  
- ✏️ Edición de notas existentes  
- 🗑️ Eliminación de notas  
- 🎨 Interfaz de usuario amigable e intuitiva  

## ⚙️ Instalación

1. 📦 Instalar las dependencias necesarias:
```bash
pip install -r requirements.txt
```
2. 🚀 Ejecutar la aplicación:
```bash
python manage.py runserver
```
3. 🔗 Acceder a la app en http://localhost:8000/
4. Ejecutar la semilla de datos:
```bash
http://127.0.0.1:8000/notes/api/seed
```
